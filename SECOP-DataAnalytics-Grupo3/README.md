# SECOP - Data Analytics | Grupo 3

## Descripción del proyecto

Este proyecto corresponde a una investigación y análisis de datos
relacionados con SECOP, desarrollada por el Grupo 3.

El trabajo se organiza en un notebook de Jupyter, donde se realizan
las actividades de exploración y análisis de los datos, y en una
carpeta destinada a los archivos complementarios del proyecto.

## Objetivos

- Explorar y analizar los datos utilizados en la investigación.
- Aplicar técnicas de análisis de datos mediante Python.
- Organizar los archivos y resultados del proyecto.
- Documentar el proceso de investigación y sus resultados.
